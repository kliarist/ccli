# Phase 2 — TUI Design Contract

> Visual and interaction contract for the Ratatui/crossterm TUI. Terminal context only — no HTML, CSS, or browser concepts. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> All decisions below are pre-populated from: 02-CONTEXT.md (D-10 through D-25), 01-CONTEXT.md (D-01 through D-09), and REQUIREMENTS.md (TUI-01..06, SPC-01..04).

## Spacing Scale

Terminal UIs measure in character cells, not pixels. All dimensions are in columns (horizontal) or rows (vertical).

| Token | Cells | Usage |
|-------|-------|-------|
| gap-none | 0 | Adjacent widgets with shared borders |
| gap-xs | 1 | Inner block padding (horizontal), label-to-value gap |
| gap-sm | 2 | Inner block padding (vertical) |
| gap-md | 1 row | Status bar height, help bar height |
| gap-lg | n/a | Not applicable — layout uses Constraint, not fixed offsets |

Layout constraints (Ratatui `Constraint` enum):

| Region | Constraint | Value | Source |
|--------|------------|-------|--------|
| List pane (horizontal) | `Constraint::Percentage` | 40% | D-20 |
| Preview pane (horizontal) | `Constraint::Percentage` | 60% | D-20 |
| Main body (vertical, flexible) | `Constraint::Min(0)` | fills remaining rows | discretion |
| Status bar (vertical) | `Constraint::Length` | 1 row | discretion |
| Help bar (vertical) | `Constraint::Length` | 1 row | D-13 |
| Filter input overlay (vertical) | `Constraint::Length` | 3 rows (1 border + 1 input + 1 border) | D-15 |

Block inner padding: `Padding::horizontal(1)` applied to every `Block` widget (1-cell left + right margin inside borders).

## Typography

Terminal "typography" = crossterm `Modifier` flags applied to `Style`. Monospace font is always inherited from the host terminal.

| Role | Modifier | Usage |
|------|----------|-------|
| Normal body | (none) | Space list rows, preview field values |
| Bold | `Modifier::BOLD` | Column headers, preview field labels (Key, Name, Type, Description, URL), selected list item |
| Dim | `Modifier::DIM` | Fallback `—` for empty fields, `No description` placeholder text, item count in status bar when filter is inactive |
| Bold + underline | `Modifier::BOLD \| Modifier::UNDERLINED` | Active filter query text in the filter input block title |
| Italic | (not used) | Reserved — not available in all terminals |

## Color

crossterm `Color` enum values. No RGB — restricts to 16 ANSI colors for broadest terminal compatibility (including SSH/mosh/tmux sessions per D-23 context).

| Role | crossterm Value | Usage | Source |
|------|----------------|-------|--------|
| Default background | `Color::Reset` | All widget backgrounds; inherits terminal background | terminal constraint |
| Default foreground | `Color::Reset` | Normal text, unselected list rows | terminal constraint |
| Accent — selected row | `Color::Cyan` | Background of the currently highlighted list row | discretion (monochrome + single accent, D-context) |
| Accent — selected row text | `Color::Black` | Foreground of the currently highlighted list row (readable on Cyan bg) | contrast |
| Accent — filter cursor | `Color::Cyan` | Cursor block in the filter input field | D-15 |
| Accent — filter query text | `Color::Cyan` | The typed query characters in the filter block title | D-15 |
| Accent — active border | `Color::Cyan` | Border of the list pane block when filter is active | D-15 |
| Dim text | `Color::DarkGray` | Empty field fallback `—`, `No description`, status-bar counts when idle | D-21 |
| Status bar background | `Color::Reset` | Status bar row background (no distinct color) | discretion |
| Status bar foreground | `Color::Reset` | Status bar text (normal) | discretion |
| Error text | `Color::Red` | Inline error message in status bar | discretion |
| Help bar background | `Color::Reset` | Bottom help bar background | D-13 |
| Help bar key labels | `Color::Cyan` | The key characters (e.g., `/`, `o`, `q`) in the help bar | D-13 |
| Help bar description text | `Color::Reset` | Verb after each key label (e.g., "filter", "open") | D-13 |
| Spinner | `Color::Cyan` | Spinner character in status bar during load | D-14 |
| Border (normal) | `Color::Reset` | Block borders when not focused/active | discretion |

Accent (`Color::Cyan`) is reserved for: selected row highlight, filter cursor, filter query text, active-state pane border, help bar key labels, spinner. Never applied to static body text.

## Widget Hierarchy

### Root frame

`Block::new()` with no borders — frame fills the entire terminal area.

### Title Block

`Block::default()`
- `Borders::BOTTOM` only (single bottom border separates title from main body)
- `BorderType::Plain`
- Title text: `"Spaces"` — `Style::default().add_modifier(Modifier::BOLD)`
- Right-aligned subtitle: `"{N} total / {M} shown"` — `Style::default().add_modifier(Modifier::DIM)`
  - When filter is inactive: `"{N} total"`
  - When filter is active: `"{N} total / {M} shown"`
  - During load: `"Loading…"` (spinner replaces count — see Loading State)

### List Pane Block

`Block::default()`
- `Borders::RIGHT` (divider between list and preview; no outer borders)
- `BorderType::Plain`
- Normal state border style: `Style::default().fg(Color::Reset)`
- Active filter state border style: `Style::default().fg(Color::Cyan)`
- Inner padding: `Padding::horizontal(1)`

List widget: `List::new(items)`
- Selected item style: `Style::default().bg(Color::Cyan).fg(Color::Black).add_modifier(Modifier::BOLD)`
- Unselected item style: `Style::default()`
- Highlight symbol: `"> "` (2 chars, accounts for alignment offset)
- `List::highlight_spacing(HighlightSpacing::Always)` — reserve 2-char gutter always, prevents layout shift on navigation

List item format: `"{KEY:<8} {name}"` — key left-padded to 8 chars, name truncated with `"…"` if it would overflow the pane width.

### Preview Pane Block

`Block::default()`
- `Borders::NONE`
- Inner padding: `Padding::new(1, 1, 0, 0)` (left + right margin only)

Content: `Paragraph::new(text)`
- `Wrap::new(true).trim(true)` for description field; all other fields are single-line

Preview field layout (rendered as a `Text` with styled `Line` spans):

```
Key:          {value}
Name:         {value}
Type:         {value}
Description:  {value or "No description" (DIM)}
Homepage URL: {value or "—" (DIM)}
```

Field labels: `Style::default().add_modifier(Modifier::BOLD)`
Field values: `Style::default()`
Missing value fallback (`—`): `Style::default().fg(Color::DarkGray).add_modifier(Modifier::DIM)`
`No description` text: `Style::default().fg(Color::DarkGray).add_modifier(Modifier::DIM)`

Column alignment: label column is padded to 14 chars (`"{:<14}"`) so values align vertically.

### Status Bar

Single `Paragraph` row, no block borders.

States:

| State | Content | Style |
|-------|---------|-------|
| Loading | `" {spinner_frame}  Loading spaces… {fetched}/{estimated}"` | spinner char in `Color::Cyan`, text in `Color::Reset` |
| Idle (no filter) | `" {N} spaces"` | `Color::DarkGray` |
| Filter active | `" {M}/{N} spaces match"` | `Color::Reset` for `{M}`, `Color::DarkGray` for `"/{N} spaces match"` |
| Error | `" Error: {message}"` | `Color::Red` |
| Browser fallback | `" Browser unavailable — URL printed to stderr. Press any key…"` | `Color::Red` |

Status bar is 1 row, `Constraint::Length(1)`, no border.

### Help Bar

Single `Paragraph` row, no block borders.

Static content for Spaces view:

```
 /  filter   o  open   ?  help   q  quit
```

Rendering: alternating spans — key chars in `Color::Cyan` + `Modifier::BOLD`, separator and description in `Color::Reset`.

Exact spans:

```rust
vec![
    Span::styled(" /", Style::default().fg(Color::Cyan).add_modifier(Modifier::BOLD)),
    Span::raw("  filter   "),
    Span::styled("o", Style::default().fg(Color::Cyan).add_modifier(Modifier::BOLD)),
    Span::raw("  open   "),
    Span::styled("?", Style::default().fg(Color::Cyan).add_modifier(Modifier::BOLD)),
    Span::raw("  help   "),
    Span::styled("q", Style::default().fg(Color::Cyan).add_modifier(Modifier::BOLD)),
    Span::raw("  quit"),
]
```

### Filter Input Overlay

Activated by `/`. Rendered as an inline block replacing the list pane title area (appended below the title block, above the list rows), constrained to the list pane width.

Layout position: overlaid at the top of the list pane using a `Rect` computed from the list pane area: `Rect { x, y, width: list_pane_width, height: 3 }`.

Widget: `Paragraph::new(filter_text)` inside a `Block`:
- `Borders::ALL`
- `BorderType::Rounded`
- Border style: `Style::default().fg(Color::Cyan)`
- Title: `"Filter"` in `Style::default().fg(Color::Cyan).add_modifier(Modifier::BOLD)`
- Cursor: rendered as a trailing `"█"` character appended to the query text, styled `Style::default().fg(Color::Cyan)`

The filter input block is 3 rows tall (top border + input row + bottom border). It overlays the top of the list pane — it does not shift the list layout.

### Help Modal (`?`)

Full-screen centered `Clear` + `Block` overlay:

Dimensions: `Rect { width: 50, height: 14, centered in terminal area }`

Block:
- `Borders::ALL`
- `BorderType::Rounded`
- Border style: `Style::default().fg(Color::Cyan)`
- Title: `" Key Bindings "` in `Modifier::BOLD`

Content (`Paragraph` inside block):

```
Navigation
  ↑ / k    Move up
  ↓ / j    Move down

Actions
  o        Open in browser
  /        Start filter
  Esc      Close filter / dismiss
  ?        Show this help

Application
  q        Quit
```

Key column: 12 chars wide, left-aligned. Description column: remainder.
Section headings: `Modifier::BOLD`.
Key chars: `Style::default().fg(Color::Cyan)`.
Description text: `Style::default()`.

## Loading State

Spinner frames (text-only, ASCII, 8 frames at 100ms interval):

```rust
const SPINNER_FRAMES: &[&str] = &["◐", "◓", "◑", "◒", "◐", "◓", "◑", "◒"];
```

Tick rate: 100ms tick drives spinner advancement. The tokio event loop `select!`s over a `tokio::time::interval(Duration::from_millis(100))` tick alongside crossterm key events.

Status bar content during load:
```
 {spinner_frame}  Loading spaces… {fetched}/{total_pages_estimated}
```

When total is unknown (before first API page returns): `"Loading spaces…"` with no count.
When total is known: `"Loading spaces… {fetched}/{total}"` using `size` from first API response.

After load completes: status bar transitions to idle state (see Status Bar section).

                ▼
         ┌─────────────┐

    │       │      │                           │
    │      `?`     `/`                         │
    │       │      │                           │
    │       ▼      ▼                           │
    │  ┌────────┐ ┌────────────┐               │

    │  └───┬────┘ └─────┬──────┘               │

## Fetch & Debounce Contract

### Initial Space List Fetch (D-14)

- Trigger: on TUI launch, before first render
- Walk all pages of `GET /rest/api/space` (25 per page, default)
- Show spinner during walk (see Loading State)
- On complete: sort by `key` ascending (discretion), transition to Browse state
- On error: display error in status bar (see Error Display)

### Preview Detail Fetch (D-19)

- Trigger: highlight settles on a new space after 150ms debounce
- Endpoint: `GET /rest/api/space/{key}?expand=description.plain,homepage`
- While pending: preview pane shows previous content (no spinner in preview pane itself)
- On complete: render new content immediately
- On error: preview pane shows `"Could not load details — {error message}"` in `Color::Red`
- Session cache: `HashMap<SpaceKey, SpaceDetail>` — cache hit skips fetch, no debounce needed

## Error Display Contract

| Error origin | Display location | Style | Copy pattern |
|-------------|-----------------|-------|--------------|
| Space list fetch failure (initial load) | Status bar, full width | `Color::Red` | `"Error: {message}  Run 'ccli init' to reconfigure."` |
| Preview detail fetch failure | Preview pane, replaces content | `Color::Red` | `"Could not load details: {message}"` |
| Browser open failure (`open::that()` error, D-23) | Suspend TUI, print to stderr | terminal default | `"Browser unavailable — open this URL manually:\n  {url}\n\nPress any key to continue."` |
| Auth error (401/403) | Status bar | `Color::Red` | `"Authentication failed. Run 'ccli init' to reconfigure."` |
| Network error | Status bar | `Color::Red` | `"Network error: {message}"` |

After displaying a status bar error: error persists until the next successful action (navigation keypress clears non-fatal errors).

## Empty State Contract

| State | List pane content | Preview pane content |
|-------|------------------|---------------------|
| Before load completes | `"Loading…"` centered, `Color::DarkGray` | `"Select a space to preview"`, `Color::DarkGray` |
| Load succeeded, 0 spaces accessible | `"No spaces accessible"`, `Color::DarkGray` | `"No space selected"`, `Color::DarkGray` |
| Filter active, 0 matches | `"No matches for \"{query}\""`, `Color::DarkGray` | `"No space selected"`, `Color::DarkGray` |
| Filter cleared (Esc) | Full list restored immediately (no reload) | Restore previously shown preview |

Empty list states are rendered as a single centered `Paragraph` inside the list pane block, not as a `List` widget (avoids empty List widget quirks).

## SSH / Headless Fallback Flow (D-23)

Triggered when `open::that(url)` returns `Err(_)`:

1. Call `disable_raw_mode()` and execute `crossterm::execute!(stdout, LeaveAlternateScreen)` to suspend TUI.
2. Print to stderr:
   ```
   Browser unavailable — open this URL manually:
     {url}
   
   Press any key to continue.
   ```
3. Read one keypress from stdin (blocking).
4. Re-enter alternate screen: `crossterm::execute!(stdout, EnterAlternateScreen)` and `enable_raw_mode()`.
5. Redraw full TUI state.

This flow does NOT check `$SSH_CONNECTION`, `$DISPLAY`, or `$WAYLAND_DISPLAY` before attempting — attempt first, react on failure (D-23).

## Panic Safety Contract

Install a panic hook before entering the TUI event loop:

```rust
let original_hook = std::panic::take_hook();
std::panic::set_hook(Box::new(move |info| {
    // Restore terminal before printing panic message
    let _ = disable_raw_mode();
    let _ = crossterm::execute!(std::io::stderr(), LeaveAlternateScreen);
    original_hook(info);
}));
```

This ensures a panic during rendering or async fetch does not leave the user in raw mode. Required for every Ratatui application; must be installed in `tui::run()` before `enable_raw_mode()`.
