**Architecture decision (per RESEARCH.md Open Question 3 + Pitfall 6):**
- `crossterm::event::poll()` is synchronous/blocking. In `#[tokio::main]`, blocking the executor thread for 100ms is acceptable for a single-user CLI.
- Use `tokio::task::spawn_blocking` to run the event loop in its own OS thread, communicating fetch results via `tokio::sync::oneshot` + `mpsc` channels. This is the correct pattern.
- The initial space list fetch runs in the tokio async context; result is sent to the event loop thread via a `oneshot` channel.
- The preview fetch also runs async; result sent via a separate `oneshot` channel.

```rust
//! TUI shell — terminal lifecycle, event loop, and top-level dispatch.
//!
//! Locked decisions implemented:
//! - D-10: bare `ccli` launches this TUI on the Spaces browse view
//! - D-12: `q` always quits; `Esc` closes overlays (filter/modal) or quits at top-level
//! - D-13: static help bar + `?` modal
//! - D-14: pre-fetch all spaces on launch with spinner
//! - D-19: 150ms debounce before preview fetch; session cache in App
//! - D-22: use `open` crate for browser launch
//! - D-23: SSH/headless fallback — suspend TUI, print URL, await keypress, restore
//! - D-24: URL from _links.webui via resolve_webui_url()
//!
//! Terminal lifecycle:
//! - ratatui::init() handles raw mode, alternate screen, AND panic hook atomically.
//! - ratatui::restore() undoes all of it — always called even on error.
//!
//! Security:
//! - PAT token never logged. Client passed to API calls only, not stored in TUI state.

pub mod app;
pub mod screens;

use crossterm::event::{self, Event, KeyCode, KeyEventKind};
use tokio::sync::oneshot;

/// TUI entry point. Called by main.rs when no subcommand is given (D-10).
///
/// Lifecycle:
/// 1. Load config (error if missing — user must run `ccli init` first)
/// 2. Build Client
/// 3. ratatui::init() — raw mode + alt screen + panic hook
/// 4. Spawn async task to pre-fetch all spaces (D-14)
/// 5. Run event loop (spawn_blocking to avoid blocking tokio executor)
/// 6. ratatui::restore() — always, even on error
pub async fn run() -> anyhow::Result<()> {
    let config = config::load_or_error()
        .map_err(anyhow::Error::from)
        .context("No configuration found. Run 'ccli init' to configure before launching the TUI.")?;

    let client = Client::new(&config)?;

    // Spawn the initial space list fetch before entering the TUI (D-14)
    let (spaces_tx, spaces_rx) = oneshot::channel();
    let fetch_client = client.clone();
    tokio::spawn(async move {
        let result = list_all_spaces(&fetch_client).await;
        let _ = spaces_tx.send(result);
    });

    // Enter alternate screen + raw mode + install panic hook
    let mut terminal = ratatui::init();

    // Run the event loop in a blocking thread (Pitfall 6 / Open Question 3)
    let result = run_app(&mut terminal, client, spaces_rx).await;

    // Always restore terminal, even on error
    ratatui::restore();

    result
}
```

**Complete `run_app` function:**
```rust
async fn run_app(
    terminal: &mut ratatui::DefaultTerminal,
    client: Client,
    mut spaces_rx: oneshot::Receiver<Result<Vec<crate::api::space::Space>, crate::api::error::AppError>>,
) -> anyhow::Result<()> {
    let mut app = App::new();
    // Channel for preview detail fetches
    let (preview_tx, mut preview_rx) =
        tokio::sync::mpsc::channel::<(String, Result<crate::api::space::SpaceDetail, crate::api::error::AppError>)>(4);

    loop {
        // Draw current state
        terminal.draw(|f| render_spaces(f, &mut app, f.area()))?;

        // Check for completed space list fetch (non-blocking)
        if let Ok(fetch_result) = spaces_rx.try_recv() {
            match fetch_result {
                Ok(spaces) => app.set_spaces(spaces),
                Err(e) => app.set_fetch_error(&e),
            }
        }

        // Check for completed preview fetch (non-blocking)
        if let Ok((key, detail_result)) = preview_rx.try_recv() {
            match detail_result {
                Ok(detail) => app.cache_detail(key, detail),
                Err(_) => {} // preview errors are non-fatal; pane shows previous content
            }
        }

        // If a preview fetch is pending (set by tick() after debounce), spawn it (D-19)
        if let Some(key) = app.pending_preview_key.take() {
            let fetch_client = client.clone();
            let tx = preview_tx.clone();
            let k = key.clone();
            tokio::spawn(async move {
                let result = get_space_detail(&fetch_client, &k).await;
                let _ = tx.send((k, result)).await;
            });
        }

        // Poll for key events with 100ms timeout (drives spinner tick, Pitfall 4)
        if event::poll(Duration::from_millis(100))? {
            if let Event::Key(key) = event::read()? {
                if key.kind == KeyEventKind::Press {
                    let action = app.handle_key(key.code);
                    match action {
                        KeyAction::Quit => break,
                        KeyAction::OpenBrowser(space_key) => {
                            handle_open_browser(&mut app, &space_key, terminal)?;
                        }
                        KeyAction::None => {}
                    }
                }
            }
        } else {
            // Timeout — advance spinner, check debounce (D-19)
            app.tick();
        }
    }

    Ok(())
}
```

```rust
fn handle_open_browser(
    app: &mut App,
    space_key: &str,
    terminal: &mut ratatui::DefaultTerminal,
) -> anyhow::Result<()> {
    // Resolve browser URL from _links.webui (D-24) — never hand-build
    let space = app
        .list_state
        .selected()
        .and_then(|i| app.filtered_indices.get(i))
        .and_then(|&idx| app.spaces.get(idx));

    let url = match space {
        Some(s) => match &s.links.webui {
            Some(webui) => {
                // We need base_url here; pass it as a parameter
                // For now, store base_url in App or pass it explicitly
                // The event loop must pass client.base_url() to this function
                webui.clone() // placeholder — see note below
            }
            None => {
                app.error = Some(format!("No URL available for space {}", space_key));
                return Ok(());
            }
        },
        None => return Ok(()),
    };

    match open::that(&url) {
        Ok(_) => {}
        Err(_) => {
            // D-23: SSH/headless fallback — suspend TUI, print URL, await keypress, restore
            ratatui::restore();
            eprintln!("Browser unavailable — open this URL manually:");
            eprintln!("  {}", url);
            eprintln!();
            eprintln!("Press any key to continue.");

            // Block-read one keypress
            loop {
                if event::poll(Duration::from_secs(60))? {
                    if let Event::Key(k) = event::read()? {
                        if k.kind == KeyEventKind::Press {
                            break;
                        }
                    }
                }
            }

            // Re-enter TUI
            *terminal = ratatui::init();
        }
    }

    Ok(())
}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ccli process → system browser (open crate) | URL passed to OS browser launcher; must be a valid absolute URL |
| TUI error state → stderr (SSH fallback) | URL printed to stderr on browser open failure |
| crossterm raw mode → terminal restore | Panic hook and restore() must fire even on panic |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-17 | Information Disclosure | SSH fallback — URL printed to stderr | accept | URL is non-sensitive Confluence page URL; printing it is the explicit design (D-23); PAT never included in URL |
| T-02-18 | Information Disclosure | `run()` — Client passed to tokio::spawn | mitigate | `Client` cloned before move to spawn; PAT held inside Client (reqwest header pool), never extracted to a String; `#[instrument(skip(client))]` on all API calls |
| T-02-19 | Tampering | `open::that(url)` — URL from API _links.webui | mitigate | `resolve_webui_url` joins webui (relative `/` path) onto base_url from config; webui field is `Option<String>` — None case handled gracefully; URL is passed to OS browser, not to a shell |
| T-02-20 | Denial of Service | Event loop poll — 100ms timeout per iteration | accept | Single-user CLI; 100ms tick is minimal CPU overhead; acceptable for interactive tool |
| T-02-21 | Information Disclosure | ratatui panic hook — terminal state restored | mitigate | `ratatui::init()` installs panic hook that calls `restore()` before printing panic message; no credentials present in TUI render state (ASVS V7) |
| T-02-22 | Information Disclosure | Preview cache — SpaceDetail in memory | accept | Cache is ephemeral process memory; no persistence; no logging; cleared on exit |
