pub struct Comment {

pub async fn list_comments(client: &Client, page_id: &str) -> Result<Vec<Comment>, AppError>;

Endpoints used:
- `GET /rest/api/content/{id}/child/comment?expand=body.storage,version&limit=50` (list_comments)

Notable: The `cli/comment.rs` plain-text-to-storage-XML wrapping contract was implemented in Phase 4 (STATE.md decisions log). add_comment receives storage-formatted XML, not raw plain text — wrapping happens in the CLI handler before calling the API.
